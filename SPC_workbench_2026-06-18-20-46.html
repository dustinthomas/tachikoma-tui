A
Size binning (optional)

What this is for. Use size binning only when your data has one row per individual item (e.g. one row per measured particle or defect), each with a numeric size. The workbench then counts how many rows fall into a size range, grouped per subgroup (e.g. per wafer), and plots that count/proportion as an attribute chart. If you instead have one measurement per wafer/run (typical metrology), leave this Off and use the Data column above with an I-MR / X̄-R chart.

In the top section (02), when binning is ON:

  • Chart name & Process / parameter — fill in normally.
  • Chart type — pick an attribute chart: p (proportion of rows in the bin), np (count in the bin — needs equal subgroup sizes), or u. The variables types (I-MR, X̄-R, X̄-S) don't apply to binned counts.
  • Units — optional label only.
  • Data column & Sample-size column — ignored; leave them as-is. The plotted count comes from the bin, and n comes from the number of rows in each subgroup.
  • Optional Tool / Timestamp / Lot columns — still used for labels & filtering if you set them.

In section (A) below:

  • Size column — the numeric column holding each row's size (e.g. Value = defect size in µm).
  • Subgroup column — what makes one chart point (e.g. Wafer or Lot); one point per unique value.
  • Bin definitions — comma-separated ranges, e.g. 0-5, 5-10, 10-. Each range is left-inclusive, right-exclusive; the final closed bin includes its upper bound. Use -5 for "< 5" or 15- for "≥ 15".
  • Selected bin — the single bin this chart plots (one chart = one bin).
Worked example — particles ≥ 10 µm per wafer (p-chart)
Data: one row per detected particle, with columns Wafer (W01, W02, …) and Value (particle size in µm). Goal: track the fraction of particles that are ≥ 10 µm on each wafer.
  • Chart type = p
  • Enable size binning = On
  • Size column = Value;   Subgroup column = Wafer
  • Bin definitions = 0-5, 5-10, 10-
  • Selected bin = 10-  (≥ 10 µm)
Each wafer becomes one point = (particles ≥ 10 µm on that wafer) ÷ (total particles on that wafer). To instead plot the raw count per wafer, choose chart type np (when every wafer has the same number of measurements) or c/u for defect-rate styles.

Data & Excel import / export
Excel template format
Import is performed against a worksheet named Data (or the first sheet if not present). The first row contains column names; subsequent rows are observations. Column names you assign in the builder must match exactly. Recommended columns:
  • Timestamp — date/time of measurement (Excel date or ISO string)
  • Tool — equipment ID (e.g. ETCH-A, LITHO-2) — used for tool filtering
  • Lot / Wafer / Chip — traceability (optional)
  • Value — the measurement (numeric) for variables charts
  • Defects + n — for attribute charts (p, np, u)
  • Add any custom columns you want — they will be available in the builder dropdowns
Rows are appended by default — re-importing the same file twice will duplicate rows. Use Replace mode in the import dialog to overwrite.

Western Electric Rules — defaults
About these rules
Western Electric Co. defined a set of decision rules to detect non-random patterns on Shewhart control charts. The classic four are WECO 1–4; WECO 5–8 are common Nelson supplements. Each chart you build picks which rules to evaluate; defaults below are used for new charts. Rules apply against the chart's center line (CL) and standard-deviation zones (1σ, 2σ, 3σ).
What does each rule signal?

Instructions & SharePoint workflow
Quick start
  1. Go to Tools registry and add your fab tools.
  2. Go to Data & import, click on the dropdown menu Generic (Value column) and select a template, then click Download blank template, fill it in Excel, then Import Excel.
  3. Go to Build new chart, fill in name + type, pick the data column and any rules, then Save chart.
  4. Switch to the Charts tab to view; violations are flagged in red below each chart.
  5. Press Ctrl+S (or click Save in the masthead) to persist your work into this HTML file.
Definitions — chart type
The chart type determines how points are computed and which control limits apply. Pick the type that matches your data: continuous measurements use the variables charts (I-MR, X̄-R, X̄-S); pass/fail or defect counts use the attributes charts (p, np, c, u).
TypeData / classDefinition & when to use
I-MRVariables (continuous)Individuals & Moving Range. One measurement per time point. Plots each individual value, with a moving range (absolute difference between consecutive points) estimating short-term variation. Use when subgrouping is impractical — e.g. one wafer per run, slow processes, destructive tests.
X̄-RVariables (continuous)Subgroup mean & range. Plots the average of each subgroup, with the range (max − min) tracking within-subgroup spread. Best for small subgroups (n ≤ ~8 to 10), e.g. several measurements per lot.
X̄-SVariables (continuous)Subgroup mean & standard deviation. Like X̄-R but uses the subgroup standard deviation (s) instead of range to track spread — more efficient for larger subgroups (n > ~10).
pAttributes (pass/fail)Proportion defective. Fraction of defective units per sample (defects ÷ n). Use for go/no-go inspection where the sample size (n) varies between subgroups.
npAttributes (pass/fail)Count defective. Number of defective units per sample. Equivalent to the p-chart but plots raw counts — requires a constant sample size (n).
cAttributes (defect count)Count of defects. Total number of defects in a fixed-size inspection unit (a unit may have multiple defects). Requires a constant inspection area/sample size — e.g. defects per wafer.
uAttributes (defect count)Defects per unit. Defects ÷ n, where the inspection area or sample size varies between samples. Use instead of a c-chart when the unit size is not constant.
SharePoint shared-database workflow
This file is fully self-contained: charts, tools, data, and rule defaults all live inside the HTML once you save. To share:
  1. Click ⬇ Download copy — this writes a new HTML file with all your current data baked in.
  2. Upload that HTML to your SharePoint document library (e.g. Tempe TFLN/SPC/SPC_workbench.html).
  3. Open it from SharePoint via Open in browser; or click Edit → Open in app and choose your local browser if you need full read/write.
  4. To save changes back: click ⬇ Download copy, then re-upload (or use SharePoint Replace on the existing file). For multiple editors, version-control via SharePoint's built-in versioning.
  5. Note: browser-based HTML cannot directly write back to SharePoint without an Office add-in or Power Automate flow. The download-and-replace pattern is the simplest reliable workflow. For automated round-tripping, host the file behind a SharePoint Framework (SPFx) web part that wraps the Graph API.

Limits & caveats
  • Sample-size factors are tabulated for n ∈ [2, 25].
  • Auto control limits use phase-1 estimation (entire dataset). Lock limits via Manual mode for phase-2 monitoring.
  • WECO 5–8 require contiguous sequences; ensure rows are in chronological order before computing.
  • This workbench does not perform Cpk/Ppk capability analysis — use a dedicated tool for that.
